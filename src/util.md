# getDeck関数

## 入力（引数）
なし

## 出力（戻り値）
array {array} 山札（カードオブジェクト配列）

## 設計書
1. トランプカードを表すカードオブジェクトの配列を戻りとして返却する

### 備考
* ジョーカーを除く52枚であること
* 1枚のカードは { suit: string, rank: string } のオブジェクトで表現すること

# getRankNum関数

## 入力（引数）
rank {string} カードの数字文字列

## 出力（戻り値）
{number} 1〜13の数値

## 設計書
1. 引数 rank の値に応じて以下の分岐処理をする  
  1.1 'A' のとき 1 を戻り値として返却する  
  1.2 'J' のとき 11 を戻り値として返却する  
  1.3 'Q' のとき 12 を戻り値として返却する  
  1.4 'K' のとき 13 を戻り値として返却する  
  1.5 それ以外のとき、引数 rank を数値に変換したものを戻り値として返却する
